IT111 Concept Applications

Module 1: Evolution of Computing

In this module, it tells us the how computing has evolved through time, from simple devices used for calculations to even more complicated ones using different tools such as abacus and tally sticks, and not only that, it showed us the evolution of user interaction, from punch cards to modern AI assisted interaction that we use today and how important it is in different fields.

Module 2: Computer Systems Overview

The 2nd module introduces us to computer, how they work, what they are, and how important they are especially to our daily lives. Not only that, this module also showcases the different components of a computer such as hardware, software data, people, and procedures and their importance. It also showed us the different number system and how we calculate it.

Module 3: Connected Computing

This module covers networks, internet protocols, and web evolution alongside practical HTML and CSS development for our portfolio project. It also highlights essential cybersecurity practices and online safety.
